Reelfile

Media downloader

Save a video, extract audio, or download its captions.

YouTube, Vimeo, Wikimedia Commons, or Blender
YouTube may block downloads from this server, even for public videos.
Download
Uses captions provided by the source. TXT contains the words, while SRT and WebVTT retain their timestamps.
Video and audio tracks
Uses the default audio track if the source doesn’t offer your language. Changing codecs can take longer.
Captions
Clip range
Use seconds, M:SS, or H:MM:SS. Leave either end blank to keep that part of the source.
File extras
Run locally with yt-dlp, FFmpeg (including ffprobe), and Node.js 22+ with npm. The command fetches Reelfile’s finishing tool from GitHub and saves your files in a new folder.
